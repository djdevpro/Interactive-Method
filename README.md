# Interactive Method

Turn videos into practical methods and interactive playbooks.

Paste a video link into your AI chat with the plugin enabled.

- Get a summary, method breakdown, screenshots and a Mermaid diagram.
- Ask to go deeper for an editable Markdown playbook and a VuePress site.
- Receive documents in your language. External research runs only on request.

## Codex

```sh
codex plugin marketplace add https://github.com/djdevpro/Interactive-Method.git
codex plugin add video-method-lab@interactive-method
```

## Claude Code

```sh
claude plugin install video-method-lab --marketplace https://github.com/djdevpro/Interactive-Method.git
```

Requires Windows x64, Node.js >=22.19.0 and npm. Open a new chat after installation. Your assistant prepares the tools automatically on first use; internet access is required.
